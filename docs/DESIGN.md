# MVP 设计：对象、职责与信息流

状态：2026-09-22 逻辑提案，字段、存储与运行机制未冻结。产品目的由[MVP](MVP.md)维护。

## 对象与关系

| 对象 | 负责表达什么 |
| --- | --- |
| 项目 / Goal | 共同维护的范围、受益者、目标、成功条件和重要约束 |
| Workstream 工作线 | 围绕持续目标组织任务、责任、依赖和成果 |
| Task | 原请求、scope、执行 owner、完成条件、依赖、状态及读入基线 |
| Session / Activity | 可接续的交流或执行载体，以及其中对齐、讨论、决策、执行、核验、复盘等活动 |
| Participant / Agent Run | 参与者身份、Agent 归属、可见范围与具体授权 |
| Decision / Change | 决定命题、决定者、scope、理由、受影响对象和替代关系 |
| Risk / Issue / Action | 可能问题、已发生问题与处理动作；保留影响、责任和解除条件 |
| Artifact / Evidence / Knowledge | 实际产物、绑定条件的观察、可跨任务复用的认识 |

Task 与 Session 多对多；工作线可以跨模块，一个模块也可以参与不同工作线。只有实际需要时才创建对应对象，缺失责任、日期和承诺保持未定。

重要关系可以表达为贡献目标、依赖、影响、实现决定、被证据核验或替代旧决定。项目模型提供稳定模块/功能身份及别名，session 自行提出 tag 和关联；manager 结合具体引用、依赖、scope 与来源判断相关性。同标签不证明相关，未命中也不证明不存在。

## 五个 POV

| 视角 | 职责 |
| --- | --- |
| 项目认知者 | 调查结构与流程、整合材料、提出模型修正 |
| 任务执行者 | 理解目标、复用能力、自主执行、提供产物与自查 |
| 会话记录者 | 从可见内容提取活动、纠正、决定来源和未完成项 |
| 工作线管理者 | 综合跨任务变化，发现依赖、冲突和容量问题，提出协调动作 |
| 结果核验者 | 对照目标、规范与实际证据检查任务、综合和知识候选 |

这些是职责，不是五个常驻进程。人类的目标、优先级、领域取舍与接受责任按 scope 明确；单人可以兼任，多人不能默认由某个 Agent 的用户代表全项目。

## 信息归属与流转

```text
项目来源 / 用户目标 → 项目模型与任务理解 → Agent 自主工作
→ 阶段与会话记录 → 条件核验 → 工作状态更新 → manager 综合
                         ↓ 有长期价值的候选
                    知识准入 → Base → 后续任务和人类资料
```

源码/配置拥有实现，运行证据拥有观察，决定记录拥有意图和理由；工作记录拥有任务状态、会话活动和行动项；Base 拥有跨任务知识、主题与关系。manager 报告是指定时点的综合，引用这些 owner，不独立维护另一套事实。

初次 Base 可以为空。附加资料先区分需求、方案、作者叙述、实现和证据。过程记录保留当时认识；复盘连接后来结果，缺失历史不补写为事实。完整私人会话、一次性回答和全部调试日志不复制入 Base。

## 记录、状态与变更

会话最少保留目的、相关任务/主题、重要活动与变化、决定/证据引用、未完成项及接续动作；说明可见参与者、来源范围和缺失区间。中断保留最后可证状态，不等待最终总结才捕获重要纠正。

讨论、决定、实施、核验和接受分别表达。session 结束不等于 Task 完成，局部任务完成不等于 Goal 达成；只有明确条件和有效证据才能支持完成声明。没有稳定分母和权重不生成进度百分比。

目标、决定或接口变化时，保留旧依据，识别受影响任务与知识，再按授权更新。任务恢复和交付前复核有关变化。manager 报告说明范围、read basis、变化、已完成/未完成、依赖与冲突、需要谁判断及下一动作；覆盖不全只报告局部综合。

## 知识准入与并发

候选必须有跨任务价值、稳定主题、scope、来源、状态、实际增量和必要确认，冲突可见且已清理敏感信息。观察/推断、提案/确认、有效/替代、已验证/待验证是独立维度；进入 Base 不会自动升级其权威。

候选保留 read basis，按主题、scope、来源和替代关系比较。重复导入同一来源不重复产生动作；旧基线更新不能静默覆盖新决定，非重叠变化可合并，重叠内容重新核对。来源变化触发语义复核，不能只按文件日期判断过期。保留旧值与替代历史。

## 授权、核验与工具

Agent 可在已授权范围内调查、归纳、记录和安排自己的工作。manager 分派他人、调整共同优先级、外部消息、资源承诺及风险接受需要具体授权；已有授权持续有效。人的责任裁定基于事实和适用权限，不由摘要或失败次数自动产生。

跨用户检索和输出受共享权限约束，不能仅靠提示词防泄漏。Agent 判断语义和适用性；工具在需要时负责身份/引用解析、权限过滤、持久化、去重、版本比较、测试与事件接入。未验证事件适配前，只承诺显式调用。

结果按重要条件报告满足、不满足或尚未验证，注明来源、revision/环境、核验者和方法。自查、独立核验、人的接受、知识准入和真实使用分别记录。资料按读者问题展示用途、完整行为、变化及下一动作，关键结论能回到来源。
