# yolo-study-001 Base Store fixture（历史实验）

这是一份重置前的 **T1 内容与交互样例**，用于验证同一批项目知识能否支持多种面向人的资料形式。它不是通用扫描器、正式数据 Schema 或已确定的产品 UI，也不再代表当前项目主线。

当前主线以真实 Agent 任务为起点：先验证方向、项目规范和结果治理，再从同一次工作中提取 Knowledge Delta，伴生人类资料。本 fixture 只作为固定项目证据、阅读实验和表现形式对照；不得据此反推必须实现完整多视图 Base Store。

## 文件职责

| 文件 | 职责 |
|---|---|
| `base.fixture.js` | 唯一的案例语义数据：稳定对象、关系、流程、来源、冲突和验证记录 |
| `projection-specs.fixture.js` | 视图选择、默认焦点与展示次序；不复制项目事实 |
| `index.html` | 多视图 HTML 入口 |
| `styles.css` | 展示样式 |
| `app.js` | 从 Base 生成框架、流程、模块细节、关系和证据视图；筛选、坐标和浏览历史只保存在页面状态中 |
| `../yolo-study-001-reference-preview.html` | 已有的连续技术说明书投影 |

`base.fixture.js` 使用 JSON-compatible JavaScript 对象，是为了让样例可直接通过 `file://` 打开。这个传输形式是样例选择，不冻结未来 Agent 输出协议。

## 查看

直接打开 `index.html`。页面初始显示应用框架；选择任何对象后，可以在保持同一稳定 ID 的情况下切换到运行链路、模块细节、关系或证据。
