# Project Cognition · MVP

让人和 Agent 围绕共同项目目标持续协作：理解项目、接续任务、协调变化、核验成果并复用知识。仓库名为 `lanner`，当前仍是 MVP 设计，没有可安装产品。

`dev` 只保留当前 MVP 所需内容；完整设计、案例、Demo、调研和历史记录保存在 [archive/full-design-2026-09-22](https://github.com/Wu-Tea/lanner/tree/archive/full-design-2026-09-22)。
